# Electronics Inventory Manager

A Python-based inventory management application for electronic products. The application uses JSON to store product data and provides a menu-driven interface for managing inventory.

## Features

- Display all products
- Search products by keyword and filters
- Add new products with duplicate checking
- Update product information
- Delete products with confirmation
- Filter and sort products by category, price, and stock
- Display inventory statistics
- Generate an inventory report
- Save changes to a JSON file

## Technologies Used

- Python
- JSON
- Git and GitHub

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the application:

   `python main.py`

## Data Storage

Product information is stored in `data/electronics.json`. Changes made through the application are saved to the JSON file.
